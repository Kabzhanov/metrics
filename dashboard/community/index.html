How to participate

Three steps. Default OFF until you flip it.

  1. Get a token. Click the button below. One token per IP per hour. The plaintext token is shown exactly once — we only store its SHA-256 hash.
  2. Install mcp-metrics. github.com/Kabzhanov/metrics — open-source MCP-сервер для метрик AI-агентов.
  3. Opt-in share. Add the snippet to ~/.config/mcp-metrics/config.yaml and set share.enabled: true. Your local daemon ships anonymous batches every interval_hours.

How to delete your data

        
    
          
  • Revoke your token — DELETE /metrics/api_central.php?token=<your-token>. Stops future submissions from being accepted.
    • 
          
  • Full DSAR — not yet available. Roadmap: per-token bulk delete. For now, revoke + ask ceo@bizdnai.com for cleanup of historical rows.
    • 
          
  • Anti-poisoning — server-side whitelist (ALLOWED_MODEL_PREFIXES) drops models outside the trusted-producer list before insert.
    • 
          
  • Rate limit — 100 submissions / hour / token. Anti-abuse.
